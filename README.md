# 📦 Flexbox Project

An educational project to learn and master **Flexbox CSS concepts**.

## 🎯 Objectives

- Understand the fundamentals of Flexbox
- Learn how to build modern layouts with Flexbox
- Create responsive and flexible interfaces
- Master key properties (`display: flex`, `justify-content`, `align-items`, etc.)

## 📋 Contents

This project includes:

- **Practical Examples** : Demonstrations of Flexbox properties
- **Layouts** : Various interface structures using Flexbox
- **Responsive Design** : Adapting layouts to different screen resolutions
- **Best Practices** : Tips for clean and maintainable code

## 🛠️ Technologies Used

- **HTML5** : Semantic structure
- **CSS3** : Flexbox and Media Queries
- **Modern Browsers** : Chrome, Firefox, Safari, Edge

## 📖 Essential Flexbox Properties

### Container (Parent)
- `display: flex` - Activates Flexbox
- `justify-content` - Horizontal alignment
- `align-items` - Vertical alignment
- `flex-direction` - Sets direction (row/column)
- `flex-wrap` - Manages wrapping

### Child Element
- `flex` - Shorthand property
- `flex-grow` - Element growth
- `flex-shrink` - Element shrinking
- `flex-basis` - Base size
